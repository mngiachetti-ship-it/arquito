# Arquito · página web

Página de Arquito, la app para aprender violín: descarga del APK, precio, instalación, preguntas frecuentes y páginas legales (privacidad, términos, eliminar cuenta y botón de arrepentimiento).

El precio y el link de pago se leen en vivo del panel de administrador de la app (Firestore `config/app`), así que no hace falta editar la página para cambiarlos.
